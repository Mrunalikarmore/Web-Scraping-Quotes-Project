# Web-Scraping and Analysis Project


### 📌  Website Scraped: quotes.toscrape.com

---

## 📖 Project Overview

This project demonstrates a complete **web scraping and data analysis pipeline** using Python.

The project automatically scrapes **100 quotes from 10 webpages**, stores the extracted information in a structured format, cleans the dataset, and performs exploratory data analysis to uncover interesting insights about authors, tags, and quote patterns.

---

# 🚀 Features

✅ Scrapes data from multiple pages automatically  
✅ Extracts quotes, authors, and tags  
✅ Stores data in a structured Pandas DataFrame  
✅ Saves cleaned data into CSV format  
✅ Performs exploratory data analysis (EDA)  
✅ Generates visualizations and insights  

---
